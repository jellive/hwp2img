# hwp2img — 어머니용 HWP→이미지 변환기 설계

날짜: 2026-08-08
상태: 설계 확정 대기 (사용자 리뷰 전)

## 배경

어머니가 관공서 등에서 받는 `.hwp`(한글) 문서를 카카오톡으로 바로 보낼 수 있게
이미지로 저장하고 싶어 하심. 어머니는 컴퓨터 조작에 익숙하지 않음.

- **어머니 환경**: Windows PC, 한컴오피스 2018 설치됨
- **실행 주체**: 어머니 본인 (셀프서비스 — Jell 이 대신 처리해주는 건 근본 해결책이 아니라고 판단해 기각)
- **개발 환경**: Jell 은 Mac 사용, 어머니 PC 는 원격 접속/화면공유로만 접근 가능

## 조사 결과 요약

| 항목 | 결론 | 신뢰도 |
|---|---|---|
| 한글 "다른 이름으로 저장"에 이미지 포맷(BMP/JPG/PNG) | 없음 | 공식 도움말로 확인 |
| 한글 "파일→인쇄→그림으로 저장하기" 가상 프린터 | 있음. 페이지별 개별 파일 생성(SAMPLE001.BMP...), 약 6단계 조작 | 공식 도움말로 확인 |
| 한글 자동화(HwpCtrl COM) `SaveAs(path, "PDF")` | 공식 API, 한컴 개발자 포럼·공식 문서에 실사용 예시 다수 | 확인됨 |
| 자동화 COM 최초 실행 시 보안 경고 팝업 | 실존하는 이슈. 레지스트리(`HKCU\Software\HNC\HwpAutomation\Modules`)에 보안승인모듈 등록 시 우회, 재부팅 후에도 유지 | 확인됨 |
| pyhwpx (Python, 한글 COM 래퍼) | 활발히 유지보수 중(2026-03 배포) | 확인됨 |
| 한글 내장 스크립트 매크로로 "인쇄→그림으로 저장" 전체 무인화 | **불가능** — 저장 위치/파일명 대화상자는 매크로로 넘길 수 없어 매번 사용자 조작 필요 | agy 교차검증으로 확인, 기각 사유 |
| 온라인 hwp→이미지 변환 서비스 | 다수 존재하나 개인 문서를 외부 서버에 업로드해야 함 | 프라이버시 사유로 기각 |

## 아키텍처

```
어머니가 .hwp 파일을 exe 아이콘에 드래그
  → pyhwpx 로 한글을 열어 SaveAs(임시.pdf, "PDF")        [COM 자동화, 1줄]
  → PyMuPDF(fitz) 로 PDF 각 페이지를 PNG 렌더             [순수 Python, 별도 설치 불필요]
  → 페이지 2장 이상이면 Pillow 로 세로로 이어붙여
    "<원본파일명>_변환.png" 1장만 생성                     [멀티페이지 혼란 방지]
  → 바탕화면 "변환된사진/" 폴더에 저장
    + 클립보드에 이미지 복사
    + 그 폴더를 탐색기로 자동 오픈
  → 어머니는 카톡에서 Ctrl+V 로 붙여넣거나, 열린 폴더에서 사진 첨부
```

PDF→이미지 렌더는 `pdf2image`(poppler 별도 설치 필요) 대신 **PyMuPDF**를 쓴다 —
순수 Python wheel이라 PyInstaller 로 단일 `.exe` 패키징이 쉽고, 어머니 PC에 추가로
설치할 게 없다.

### 컴포넌트

| 모듈 | 역할 | 의존성 |
|---|---|---|
| `hwp_to_pdf.py` | pyhwpx 로 한글 COM 열어 지정 경로에 PDF 저장 | pyhwpx (내부적으로 pywin32) |
| `pdf_to_images.py` | PDF 각 페이지를 PNG로 렌더 | PyMuPDF |
| `stitch.py` | 여러 PNG를 세로로 이어붙여 1장으로 합성 | Pillow |
| `output.py` | 결과 저장, 클립보드 복사, 탐색기 오픈 | pywin32 (클립보드), `subprocess` (explorer) |
| `main.py` | 드래그앤드롭 진입점 — 인자로 받은 hwp 경로들을 순서대로 처리 | 위 전부 |

### 에러 처리 (어머니가 볼 수 있는 실패는 쉬운 말로)

- 한글이 설치되어 있지 않거나 COM 자동화 실패 → 메시지박스: "한글 프로그램을 열 수 없어요. [젤 연락처]로 연락해 주세요."
- 드롭한 파일이 `.hwp`/`.hwpx` 가 아님 → 메시지박스: "한글 문서 파일만 변환할 수 있어요."
- 그 외 모든 예외 → 메시지박스에 원본 예외 메시지 + 로그 파일 경로 표시 (Jell 이 원격으로 나중에 확인 가능하게)

## 배포 및 최초 1회 세팅

1. PyInstaller 로 `hwp2img.exe` 단일 파일 빌드
2. 원격/화면공유 세션에서:
   - 보안승인모듈을 레지스트리에 1회 등록 (재부팅 후에도 유지, 이후 팝업 없음)
   - `hwp2img.exe` 를 바탕화면에 배치, 바로가기 이름을 "한글 사진으로 바꾸기" 등 알아보기 쉽게 지정
   - **어머니의 실제 hwp 문서 하나로 그 세션 안에서 실제 변환까지 확인하고 종료** (설치 성공 ≠ 완료 — 실행되고 어머니가 원하는 결과물이 나오는 것까지 확인)

## 미검증 리스크 (실기기 테스트 시 확인)

- PDF 경유이므로 원본 hwp 레이아웃(폰트·표)이 폰트 임베딩 여부에 따라 미세하게 달라질 수 있음
- 표/이미지가 많은 복잡한 문서에서 PyMuPDF 렌더 화질(DPI 기본값)이 카톡으로 보내기에 충분히 선명한지
- 여러 페이지 세로 합성 이미지가 너무 길어져 카톡 미리보기에서 잘려 보일 가능성 (페이지 수가 많을 때)

## 스코프 아웃 (YAGNI)

- 자동 업데이트 기능
- 여러 hwp 파일 동시 드래그(배치 처리) — 필요해지면 나중에 추가
- GUI 설정 화면(해상도/색상 조절 등) — 기본값으로 충분한지 먼저 검증
- macOS/Linux 지원 — 어머니는 Windows 만 사용

## 테스트 전략

- **유닛 테스트** (Mac 에서도 가능): `pdf_to_images`, `stitch`, `output` — 실제 PDF/이미지 픽스처로 RED→GREEN
- **통합 테스트** (Windows 필요, 원격 세션): `hwp_to_pdf` 는 실제 한글 COM 자동화라 Mac 에서 검증 불가. 원격 세션에서 실제 hwp 파일로 전체 파이프라인 1회 이상 실행
- **최종 검증**: 어머니 PC 에서 실제 문서로 성공 확인 (위 "배포" 절 참조)
