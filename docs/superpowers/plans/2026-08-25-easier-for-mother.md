## 최종안 (내가 쓴다) — `DRAFT-v0` 에서 무엇이 바뀌었나

**초안은 "우클릭 → 자동업데이트 → 설치기" 순서였다. 그 순서가 틀렸다.**

- 1순위(우클릭)의 값어치가 **Win11 배치에 통째로 달려 있는데 나는 그걸 못 잰다** (C10, 두 레인 수렴)
- 2순위(자동업데이트)는 **실행 중 exe 가 자기를 못 바꿔서** 초안 형태로는 성립하지 않는다 (C5)
- 3순위(설치기)가 사실 **1순위의 선행조건**이다 (C2 순환 조건)
- 그리고 **초안이 통째로 놓친 축**이 있었다: 프로그램이 어머니에게 아무 말도 안 한다 (A4·C7·U2)

### 1단계 — 지금 바로. Windows 지식이 필요 없고 실코드로 이미 확인됐다
"말 없는 프로그램"을 고친다. **어머니가 오늘 쓰는 경로**가 나아지고, Win10/11 어느 쪽이든 유효하다.
- 변환 시작 → "바꾸는 중이에요…" 작은 창 (지금은 4~6초, 최악 30초 동안 화면에 아무것도 없다)
- 성공 → "다 됐어요! 카톡에 Ctrl+V 하세요" — argv 경로에도 (지금은 `dropzone` 에서만)
- 실패 → 안내창에 **[오류 내용 복사]** 버튼. 어머니는 카톡에 붙여넣기만 하면 된다
- 클립보드 3회 재시도 (A7)
- 부수효과: **왕복 비용이 준다.** 이번 주 실기기 결함 2건이 전부 "전화로 증상 듣기"에서 시작했다

### 2단계 — 재본 뒤에 정한다. 우클릭 메뉴
**코드 0줄로 먼저 잰다** — `.reg` 파일 하나 심고 어머니 PC(또는 Windows 장비)에서 우클릭 한 번.
- 상단에 보이면 → 그대로 간다 (설치기가 등록. C2)
- "더 많은 옵션 표시" 아래로 숨으면 → "프로그램에서 열기" 변형을 재보거나 포기한다
- 어느 쪽이든 `"%1"` 인용 검증이 따라붙는다 (C3 — 인용이 틀리면 공백 든 파일만 조용히 실패)

### 3단계 — 별도 덩어리. 자동 업데이트
codex 구조(C9)로만 성립한다: 고정 런처 + 버전별 엔진 디렉터리 + 원자적 포인터 + 해시 검증(C6).
설치 프로그램이 선행이다. **1·2단계와 비용의 자릿수가 다르다 — 지금 하지 않는다.**
